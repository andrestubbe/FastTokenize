TITLE:
FastTokenize: Ultra-Fast Zero-Allocation Multi-Language Java Lexer & ANSI Highlighting Demo ⚡

DESCRIPTION:
Showcasing the multi-language tokenization and 24-bit ANSI syntax highlighting demo in FastTokenize. Combining zero-allocation lexing, multi-language auto-detection, and 24-bit TrueColor terminal rendering, it delivers sub-microsecond code tokenization for CreamCLI and high-performance Java applications.

TECHNICAL HIGHLIGHTS:
- Zero-Allocation Token Stream: Off-heap byte buffer generation with zero GC overhead during continuous tokenization.
- 24-Bit ANSI TrueColor Rendering: Crisp terminal syntax highlighting with full editor themes including Tokyo Night (rgb(36, 40, 59)).
- Multi-Language Auto-Detection: Instant language identification and scanner resolution for 10+ programming languages.
- FastANSI CLI Styling: Fast 24-bit RGB ANSI escape generation with seamless full-line editor background containers.

PIPELINE FLOW:
1. File / Language Auto-Detect: Identifies source file types and maps appropriate lexer scanners.
2. FastTokenize Lexer: Generates structured token stream and zero-allocation style byte IDs.
3. FastANSI Terminal Engine: Converts token stream into 24-bit TrueColor escape sequences.
4. Editor Canvas Output: Renders styled code block with line-number gutter and full background container.
