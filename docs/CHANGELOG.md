# FastTokenize Changelog

## 0.1.0 [ALPHA] - 2026-08-16

- 🚀 **Initial Release**: Minimal, deterministic $O(n)$ tokenization engine for Java.
- 🎨 **Multi-Language Support**: Dedicated scanners for Java, C/C++, Python, C#, JS/TS, JSON, CSS, XML/HTML, and Markdown.
- ⚡ **Zero-Allocation Style Engine**: Generates byte-array style IDs directly mapping to character offsets for `FastTerminal` and CreamCLI.
- 🛡️ **Native AVX2 SIMD & Pure Java Fallback**: C++/AVX2 hardware acceleration on Windows x64 with 100% pure Java fallback for macOS & Linux.
- 📂 **Multi-Language Test Corpus**: Reference samples added to `docs/samples/`.
